# روزینو — Roozino 🌞

**دستیار روزمره فارسی برای اندروید** — کارها، یادداشت‌ها، یادآوری‌ها و تقویم شمسی؛ کاملاً آفلاین و فارسی.

- زبان برنامه: فارسی، رابط کاربری کاملاً RTL
- فونت: وزیرمتن (داخل APK)
- معماری: Kotlin + Jetpack Compose + Room (SQLite)
- حداقل اندروید: ۸.۰ (API 26) — هدف: اندروید ۱۵ (API 35)
- حریم خصوصی: **بدون مجوز اینترنت** — داده‌ها فقط روی گوشی می‌مانند

---

## ⚙️ ساخت خودکار APK (نیازی به نصب هیچ‌چیز نداری)

این ریپو یک GitHub Actions workflow دارد: `.github/workflows/build.yml`

1. کد را push کن (یا از وب‌گیت‌هاب فایل‌ها را بساز)
2. برو به تب **Actions** → بیلد «Build Roozino APK»
3. بعد از سبز شدن (≈۵ دقیقه):
   - **Release** → فایل `roozino-v0.1.0-alpha.apk` را دانلود کن
   - یا از بخش **Artifacts** همان بیلد
4. روی گوشی: فایل را باز کن → اگر پرسید، «نصب از منابع ناشناس» را برای مرورگر/گیت‌هاب فعال کن
5. نصب شد؟ باز کن و امتحان کن!

> نسخه فعلی **debug-signed** است؛ برای انتشار در بازار/مایکت امضای release بعداً اضافه می‌شود.

## 🛠️ ساخت دستی (اختیاری)

```bash
# پیش‌نیاز: JDK 17 و Android SDK (compileSdk 35)
git clone https://github.com/USERNAME/roozino.git
cd roozino
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

## ⚠️ محدودیت‌های صادقانه

1. **تحویل اعلان ۱۰۰٪ تضمینی نیست** — هیچ اپ اندرویدی هم نمی‌تواند این را تضمین کند. بهینه‌ساز باتری برخی گوشی‌ها (خصوصاً شیائومی/سامسونگ) اعلان‌ها را می‌فشارد؛ راهنمای فعال‌کردن «آلارم دقیق» داخل خود برنامه هست.
2. ورودی صوتی به سرویس گفتارِ خودِ گوشی وابسته است (اکثر گوشی‌های بازار دارند)؛ اگر نداشته باشند، دکمه میکروفون پیام مناسب نشان می‌دهد.
3. حذف یادداشت همیشگی است (سطل بازیافت فعلاً فقط برای کارهاست).
4. نسخه فعلی debug-sign است.

## 🔒 حریم خصوصی

- برنامه مجوز اینترنت ندارد؛ **هیچ داده‌ای از گوشی خارج نمی‌شود**
