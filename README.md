# روزینو (Roozino) ☀️

**دستیار هوشمند روزانه فارسی — کاملاً آفلاین، محافظت‌شده از حریم خصوصی**

روزینو یک اپلیکیشن اندروید بومی (Kotlin + Jetpack Compose + Room) برای مدیریت کارها، یادداشت‌ها، یادآوری‌ها و تقویم شمسی است. رابط کاربری کاملاً فارسی و راست‌به‌چپ است و هیچ مجوز اینترنتی ندارد — همه داده‌ها فقط روی گوشی شما می‌ماند.

[![Build APK](https://github.com/mctarh-eng/Roozino/actions/workflows/build.yml/badge.svg)](https://github.com/mctarh-eng/Roozino/actions/workflows/build.yml)

## 📥 گرفتن فایل APK

### روش ۱ — از بخش Releases (پیشنهادی)
1. به صفحه [Releases](https://github.com/mctarh-eng/Roozino/releases) بروید
2. فایل `Roozino-v0.1.0.apk` را دانلود کنید
3. روی گوشی نصب کنید (اگر پرسید، اجازه «نصب از منابع ناشناس» را بدهید)

### روش ۲ — از Artifacts مربوط به Actions
1. تب **Actions** → آخرین اجرای «Build APK»
2. در پایین صفحه، **Artifacts** → `Roozino-debug-APK` را دانلود کنید
3. فایل zip را باز کنید و APK داخلش را نصب کنید

## ✅ آنچه در نسخه ۰٫۱٫۰ (فاز ۱) واقعاً پیاده شده است

- ثبت **سریع یک‌خطی**: مثلاً بنویسید «فردا ساعت ۱۸ تماس با علی» → کار با یادآوری ثبت می‌شود (تشخیص امروز/فردا/پس‌فردا و ساعت؛ هیچ فرم اجباری وجود ندارد)
- **کارها**: افزودن، ویرایش، تکمیل، حذف با تأیید؛ تقسیم انجام‌شده/انجام‌نشده
- **یادداشت‌ها**: افزودن، ویرایش، حذف، **اشتراک‌گذاری متن** با اپ‌های دیگر
- **یادآوری محلی**: با AlarmManager؛ درخواست مجوز اعلان در اندروید ۱۳+؛ اگر مجوز «ساعت دقیق» نباشد، با پنجره ±۱۰ دقیقه کار می‌کند و در تنظیمات صادقانه اعلام می‌شود
- **ری‌استارت‌پذیری**: پس از خاموش/روشن شدن گوشی، به‌روزرسانی اپ یا تغییر ساعت/منطقه زمانی، یادآوری‌های آینده دوباره زمان‌بندی می‌شوند
- **تقویم شمسی دقیق**: الگوریتم استاندارد (Borkowski / jalaali-js)؛ نمایش ماه، علامت روزهای دارای مورد، انتخاب روز و دیدن موارد آن روز؛ تاریخ‌ها در دیتابیس به‌صورت میلادی استاندارد ذخیره و فقط در UI شمسی نمایش داده می‌شوند
- **جست‌وجوی فارسی**: نرمال‌سازی ي/ی، ك/ک، نیم‌فاصله، اعراب و اعداد فارسی/عربی؛ نتایج با نشان «کار» یا «یادداشت»
- **پشتیبان‌گیری/بازیابی**: خروجی/ورودی JSON با اعتبارسنجی، از طریق انتخابگر فایل اندروید
- **تم روشن/تیره** (سیستم/روشن/تیره)، فونت وزیرمتن، اعداد فارسی
- **حریم خصوصی واقعی**: بدون هیچ مجوز اینترنتی؛ `allowBackup=false`

## ⚠️ محدودیت‌های شناخته‌شده (صادقانه)

- تحلیل جمله ساده است؛ عبارت‌های پیچیده («دو روز بعد از عید») در فاز ۲ با هوش بیشتر پشتیبانی می‌شود
- در برخی دستگاه‌ها با بهینه‌سازی شدید باتری، یادآوری ممکن است با تأخیر برسد (رفتار خود اندروید است؛ در تنظیمات اپ قابل مشاهده است)
- ورودی صوتی، سبد خرید، گزارش هفتگی، ویجت و پشتیبان خودکار در فازهای بعدی است

## 🛠 ساخت محلی (اختیاری)

```bash
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

نیازمندی: JDK 17 (اندروید استودیو خودش Android SDK را می‌آورد)

## 🗂 ساختار پروژه

```
app/src/main/java/com/roozino/app/
├── data/          Room (Entities, Daos, Database), Repository, Backup
├── domain/        Jalali (تبدیل تقویم), PersianText (نرمال‌سازی و تحلیل ورودی)
├── notify/        ReminderScheduler (AlarmManager), Receivers (BOOT/TIME), NotificationHelper
├── ui/            Theme, Components (تقویم شمسی، دیالوگ‌ها), App (ناوبری)
│   └── screens/   امروز من، کارها، یادداشت‌ها، تقویم، جست‌وجو، تنظیمات
```
